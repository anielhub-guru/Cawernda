# Presentation Mode

## Understanding summary

- Add a prominent Presentation Mode control to the reminder dashboard header.
- Persist the mode across application and Mac restarts until the user disables it.
- Suppress every interruption generated by Cawenda while the mode is enabled.
- Hide reminder content and counts by default for safe use during screen sharing.
- Keep due reminders pending and signal them through a privacy-safe menu-bar icon state.
- Let the user deliberately reveal reminders without disabling suppression.

## Assumptions

- Presentation Mode controls only Cawenda interruptions, not notifications from macOS or other applications.
- A muted blue menu-bar icon background means Presentation Mode is active.
- An amber menu-bar icon background means one or more reminders are due and suppressed.
- Enabling the mode dismisses existing Cawenda overlays and stops alarm audio.
- Closing the dashboard ends any temporary reminder reveal.
- Disabling the mode processes pending due reminders immediately and resets break timing.

## Final design

Introduce a centralized observable Presentation Mode store backed by `UserDefaults`. It exposes whether the mode is enabled and whether reminders are currently waiting. All reminder, notification, popup, battery, review, daily-planning, and break-overlay entry points consult this state before presenting UI or playing audio.

The dashboard header contains a one-click presentation control with a clear active treatment and accessible label. While the mode is active, the dashboard replaces reminders and history with a privacy-safe status panel. If reminders become due, the panel says only that a reminder is waiting and offers an intentional **View Reminders** action. The reveal lasts only for the current popover session. A separate **Turn Off Presentation Mode** action restores normal behavior.

The menu-bar reminder icon has three states:

1. Default appearance when Presentation Mode is off.
2. Muted blue circular background when Presentation Mode is on.
3. Amber circular background when Presentation Mode is on and at least one reminder is due.

Due reminders remain unfired while suppressed. Turning the mode off runs the existing reminder-alert path immediately. Multiple waiting reminders never expose a public count.

## Reliability and edge cases

- Restore the persisted mode before any launch or wake overlays can appear.
- Dismiss visible reminder popups, battery popups, review overlays, lock overlays, delivered Cawenda notifications, and alarm audio when enabling the mode.
- Return the menu-bar icon from amber to blue when no due reminders remain.
- Reset the temporary reveal whenever the popover closes.
- Reset break timing when suppression ends so a lock overlay does not appear immediately.
- Preserve pending reminders without replaying unrelated battery or review alerts.

## Testing strategy

- Persisted enabled-state restoration.
- Three-state menu-bar icon selection.
- Suppression at every Cawenda interruption boundary.
- Pending reminder delivery after disabling the mode.
- Privacy-safe dashboard rendering without titles, checklists, counts, or dates.
- Temporary reveal reset when the popover closes.
- Existing overlay dismissal and alarm shutdown when enabling the mode.
- Break-timer reset when disabling the mode.

## Decision log

- Chose a full icon-background state over a small badge because it remains legible at menu-bar size.
- Chose blue for active suppression and amber for a waiting reminder.
- Chose an intentional reveal action rather than displaying reminder content automatically.
- Chose persistent manual control rather than an automatic timeout.
- Chose one centralized state source to prevent individual alert paths from bypassing suppression.
